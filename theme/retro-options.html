Ergo Light vs Teenage Engineering — calm

Both themes are generated from Ergo's own token model. The L* ladder is the same as in Ergo, so every step keeps the same lightness and roughly the same contrast as today. Only three things change: the hue per ramp, the chroma ceiling (Ergo uses ~0.045; these go up to ~0.22, whatever sRGB allows at each lightness), and a tinted paper. The semantic roles match ergo-light.tokens.json (string = green.600, comment band = amber.200, …), except for a few per-option overrides listed in the notes. To adopt an option, click Export primitives and paste the result over primitive in the tokens file. Then run bb -m generate. You don't need to change any generator.
